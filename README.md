# Dulce Capricho 🍰
Postres artesanales. Sabor que enamora.
Proyecto final - Jóvenes CreaTIvos, Ruta Avanzada.

**Página publicada:** https://valeriazambrano08.github.io/dulce-capricho/

## Funciones
- Home con marca propia y diseño responsive
- Catálogo de 12 productos con filtros por categoría
- Formulario de contacto con validaciones
- Panel de administrador con login (agregar y eliminar productos)
- Asesor de Antojos (chatbot), generador de dedicatorias y generador de posts para redes

## Tecnologías
HTML, CSS y JavaScript. Datos guardados con localStorage.

## Próximos pasos
Backend con Node, Express y MongoDB, y conexión a una API de IA.
